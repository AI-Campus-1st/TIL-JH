<github파일이름/커밋 메세지 변경 방법>
1. 파일 이름 변경
- OS의 파일 이름 변경 로직
- (사실 이름을 변경한게 아니고 경로를 바꾼거)
- git은 변경파일 추적 로직

(Example) 
260722_py.txt (삭제된 것으로 인식) -> 260722_temp_py.txt (새로 추가된 것으로 인식)
add를 연속 2개 -> renamed(내용이 같고, 이름만 수정된것으로 git이 받아들임)

git add 260722_py.txt
git add 260722_temp_py.txt


2. commit메세지 변경하고 싶을 때
- 변경사항을 만든다. (작게)
- add commit push
- 등록한 파일 단위로 commit 메세지가 기록 됨
