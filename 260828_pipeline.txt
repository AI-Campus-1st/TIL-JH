믿을 수 있는 데이터로 : "원본->정제->분석용 테이블->검증"까지

■3계층 구조
Raw -> Clean -> Mart 의 각 층의 책임

Raw : 받은 그대로, 절대 수정하지 않음
Clean : 표준화된 단일 소스. 타입/포맷/중복 정리
Mart : 질문에 답하는 형태. 집계/파생 지표


■원본(Raw)을 버리지 마라.
1. 파싱 로직은 반든시 바뀐다. 필드가 더 필요해지거나 버그를 발견했을 경우.
그럴때,
# 파싱 결과만 남았다면 -> 처음부터 다시 수집
# 원본이 있다면 -> 다시 파싱만 하면 끝

2. 절대 수정 하지 않는다.
# Raw를 고치면 "원래 무엇이 있는지"를 영원히 알 수 없게 된다.

■품질 이슈 여섯 갈래
1) 결측 : 값이 비어 있음
2) 중복 : 같은 것이 여러 번
3) 포맷 불일치 : 같은 뜻, 다른 표기
4) 타입 오염 : 숫자가 문자열
5) 인코딩 : 글자 깨짐
6) 잔여물 : 태그/공백/말머리
