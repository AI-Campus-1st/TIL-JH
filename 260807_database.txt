DB개요

Q) 분석가는 왜 DB를 배우는가 ?
-> 엑셀만으로는 넘을 수 없는 3개의 벽
    1. 엑셀 최대 행의 한계 (최대행 : 1,048,576)
    2. 데이터 요청 리드타임 (개발팀에 데이터를 요청하는게 아닌, 직접 조회하면 빠름
    3. 재작업 0회 (엑셀은 같은 파일을 계속 수정, but DB는 한 번 쿼리를 작성하면 다시 사용가능)

DBMS와 EXCEL은 무엇이 다른가 ?
- EXCEL (파일을 연 사람만 수정/어느게 최종본인지 헷갈림/실수로 삭제/100만행 넘으면 작업불가)
- DBMS (수백명이 동시에 읽고 씀, 원본은 하나 모두가 같은 값을 봄, 잘못된 작업은 통째로 롤백, 수억행도 작업가능)

※ 데이터가 커져서가 아니라, 함께 쓰기 위해 DB를 사용

DBMS - DataBase Management System(데이터베이스 관리시스템)
ex. MariaDB, MySQL, PostgreSQL, Oracle 등

SQL - 데이터베이스와 소통하는 언어
=> Structured (구조화된), Query (질의), Language (언어) : 질문을 할때 쓰는 언어

[SQL은 4가지로 구분] ※ 분석가는 DML의 SELECT에 집중합니다.
- DDL : 데이터베이스/테이블 같은 구조(스키마)를 만들고 바꾼다.(CREATE, ALTER, DROP, TRUNCATE)
- DML : 데이터를 추가(INSERT), 조회(SELECT), 수정(UPDATE), 삭제(DELETE)한다.
- DCL : 누가 무엇을 할 수 있는지 권한을 부여하고, 회수한다.(GRANT, REVOKE)
- TCL : 데이터 변경을 확정하거나 되돌린다.(COMMIT, ROLLBACK)

트랜잭션 : 쪼갤 수 없는 한 묶음 (All or Nothing, 전부 실행되거나, 전부다 실패하거나)

[데이터베이스 설계의 3단계]
1. 개념적 모델링 : 큰그림그리기. 무엇을 저장할지 정한다(사람-회원/관리자, 주문, 상품 등)
2. 논리적 모델링 : ERD단계. 정보의 구조, 규칙을 명확하게 도식화.
3. 물리적 모델링 : 실제DB생성

[서버란?] : 컴퓨터 하나 => 정보나 서비스를 네트워크를 통해 클라이언트에게 제공하는 컴퓨터 시스템
- SERVER : 내PC = 서버, 데이터 실제보관(HDD), MariaDB 서버로 운영
- CLIENT : SQL을 보내고 결과를 받아 보여 주는 창구(여러개 동시 띄우기 가능)
- PORT(문 번호) : 컴퓨터의 특정 프로그램에 접근하는 문 번호(번호가 막히면 접속불가, 방화벽 설정)
  => 방화벽 : 문들을 관리하는 애 (접근 허용, 거부 설정 가능)
