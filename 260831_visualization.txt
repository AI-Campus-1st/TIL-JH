■동적 시각화 & 정적 시각화
▷정적 시각화
  - 더 탐색할 목적 없이, 보고 싶은 정보가 명확한 대상에게 적합
  - 보고서/슬라이드/이미지
  - 결론은 작성자가 확정
▷동적 시각화(지도, 주식차트)
  - 데이터를 더 탐색해보고 싶은 목적이 있는 대상에게 적합
  - 대시보드/필터/드릴다운
  - 결론은 사용자가 발견

■실무에서의 사용 도구
▷빠른 커뮤니케이션(1회성 자료)
  - Excel, Google Spreadsheet, Python
▷대시보드 생성(반복 조회 필요, 사용자가 직접 탐색)
  - Tableau, Looker Studio, Power BI, Streamlit
▷전처리,모델링 연계(심화된 데이터 전처리 or 모델링과 함께 사용시)
  - Python(Matplotlib, Seaborn, Folium, Plotly), R, SQL

■지각 정확도 순위(Cleveland-Mcgill)
1. 공통 축 위의 위치(막대,점,선 그래프)
2. 축이 다른 위치(소형 다중 차트)
3. 길이(누적 막대의 각 조각)
4. 기울기/각도(파이 차트, 레이더)
5. 면적(버블, 트리맵)
6. 부피/색상 농도(히트맵, 3D)
