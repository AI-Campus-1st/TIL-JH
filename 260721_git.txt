github - 커뮤니티(게시판)
git - 글 관리 프로그램(올리는것 까지)
레퍼지토리 : 저장소(only-pull-me : 코드관련 강의자료,실습코드,예제코드 폴더)

[명령어]
ls : 현재 폴더안의 파일 list
mkdir : 폴더 생성
cd : 폴더 이동
git clone : 레퍼지토리 복제

- 최초 작성자(Author) 설정 방법
git config --global user.name "닉네임"
git config --global user.email "github 이메일"

- 저장소 가져오기(최초1회)
git clone 저장소 주소 
(이후에는 git pull로 가져 올거임)

- 관리 폴더 설정방법
git init : 이 폴더를 git저장소로 관리하겠다(최초1회)

- 관리폴더 지정 이후 실제 Github저장소와 연결필요
git remote add origin 저장소 주소

- 저장소에 올리기
등록 : git add 파일들 (모든 파일은 '.') -> git status 로 확인 (어떤 파일을 등록했는지)
기록남기기 : git commit -m "기록 메세지" -> git log 로 확인(commit을 제대로 찍었는지)
업로드 : git push origin master
